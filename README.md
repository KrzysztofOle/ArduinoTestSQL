# ArduinoTestSQL — eksperymenty Arduino i SQL

Archiwum niezależnych szkiców Arduino:
- `MySQL_Connector_Arduino/` — eksperymenty komunikacji z MySQL,
- `LiquidCrystal_I2C/` — wyświetlacz LCD przez I2C,
- `PomSzerTas/` — osobny szkic `.ino`.

## Uruchomienie
Otwórz wybrany plik `.ino` w Arduino IDE, wybierz zgodną płytkę i potrzebne biblioteki. W eksperymentach SQL **nie wpisuj haseł do kodu ani nie łącz testu z produkcyjną bazą**.

Brak jednolitego projektu, manifestu zależności i testów automatycznych.

## Git
Repozytorium używa historycznej gałęzi `master`. Zalecana jest osobna, bezpieczna migracja domyślnej gałęzi do `main`; nie wykonywano jej podczas audytu dokumentacji.
